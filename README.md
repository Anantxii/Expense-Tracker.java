# Expense-Tracker.java
The Expense Tracker is a simple Java console-based application used to manage daily expenses. It allows users to add, view, search, delete, and calculate total expenses efficiently. The project uses Java Collections (ArrayList) to store expense records and File Handling with Serialization to save data permanently in a file

Main Features:
Add new expenses with ID, name, and amount
View all saved expenses
Search expenses by ID
Delete expenses
Calculate total expense amount
Store data permanently using file serialization

Technologies Used:
Java
Object-Oriented Programming (OOP)
ArrayList Collection
File Handling
Serialization
Scanner Class for user input

Working:
When the program starts, it loads previously saved expenses from the file. Users can choose different options from the menu to manage expenses. Any changes made are automatically saved to the file, so the data remains available even after restarting the program.

Objective:
The main objective of this project is to demonstrate the use of Java concepts such as classes, objects, collections, file handling, exception handling, and serialization in a real-world application.
